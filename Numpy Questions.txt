Program 1: Calculate Total and Average Marks
import numpy as np

marks = np.array([85, 90, 78, 65, 95])

total = np.sum(marks)

average = np.mean(marks)

highest = np.max(marks)

lowest = np.min(marks)

print("Student Marks:", marks)

print("Total Marks:", total)

print("Average Marks:", average)

print("Highest Mark:", highest)

print("Lowest Mark:", lowest)

Output:
Student Marks: [85 90 78 65 95]
Total Marks: 413
Average Marks: 82.6
Highest Mark: 95
Lowest Mark: 65

Program 2: Addition of Two Arrays Using User Input
import numpy as np

a = []

b = []

print("Enter 5 elements for first array")

for i in range(5):
    n = int(input("Enter number: "))
    a.append(n)

print("Enter 5 elements for second array")

for i in range(5):
    n = int(input("Enter number: "))
    b.append(n)

arr1 = np.array(a)

arr2 = np.array(b)

result = arr1 + arr2

print("First Array:", arr1)

print("Second Array:", arr2)

print("Sum:", result)

Explanation
1. Two empty lists are created.
2. The user enters five elements for each list.
3. append() adds the entered values to the lists.
4. np.array() converts the lists into NumPy arrays.
5. arr1 + arr2 adds corresponding elements.
6. The result is displayed.
Program 3: Find Even and Odd Numbers
import numpy as np

a = np.array([10, 15, 20, 25, 30, 35, 40])

even = a[a % 2 == 0]

odd = a[a % 2 != 0]

print("Original Array:", a)

print("Even Numbers:", even)

print("Odd Numbers:", odd)

Output:
Original Array: [10 15 20 25 30 35 40]

Even Numbers: [10 20 30 40]

Odd Numbers: [15 25 35]
